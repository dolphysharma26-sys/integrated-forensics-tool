## Features

### 1\. Secure Drive Eraser

* Multiple erasure standards (DoD 5220.22-M, NIST 800-88)
* SSD and HDD support
* Verification mechanisms
* Audit logging

### 2\. Secure File \& Folder Eraser

* Individual file erasure
* Metadata cleansing
* Residual trace removal
* Batch operations

### 3\. Advanced File Carving \& Recovery

* Signature-based carving
* Structure-based carving
* Fragmented file reconstruction
* Confidence scoring
* ML-based classification

## Technology Stack

* Python 3.11
* C/C++ for low-level operations
* Sleuth Kit for forensic foundation
* PostgreSQL for data storage
